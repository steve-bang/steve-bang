# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository nature

This is a GitHub **profile repository** (`steve-bang/steve-bang`). Its only tracked file is `README.md`, which GitHub renders on the owner's profile page. There is no source code, build system, package manifest, linter, or test suite, so there are no build/lint/test commands.

## README.md

- Written as GitHub-flavored Markdown with embedded HTML (`<h1 align="center">`, `<p align="left">`, `<a>`/`<img>` tags) for alignment and the "Languages and Tools" icon row.
- Sections: intro/headline, current projects and collaboration links, learning topics, articles link, contact, social links, and a tech-icon row.
- Tech icons are `<img>` tags pointing at externally hosted SVGs (devicon, vectorlogo.zone, svgrepo). To add a tool, copy an existing `<a><img/></a>` entry in the icon row and change the link, `src`, and `alt`.
- Changes are previewed only by rendering on GitHub; there is nothing to run locally.
